I then followed these steps:

#### Challenge Encountered and Solution

During the configuration of Johnny GUI, I encountered an error message:

`No valid John The Ripper executable detected at this path!`

At first, Johnny could not detect John the Ripper because the selected path did not point to the correct executable.

**How I solved the problem:**

1. I went back to the extracted John the Ripper folder.
2. Opened the `run` directory.
3. Located the `john` application.
4. Returned to Johnny GUI settings.
5. Used Browse to select the correct executable.
6. Confirmed that Johnny successfully detected it.

After correcting the path, the error was resolved, and I continued with the PDF password-cracking exercise.

**What I learned:**

I learned how important it is to select the correct executable when configuring an application. I also improved my troubleshooting skills by identifying the cause of the error and correcting it.
